Project---PizzaHub Landing Page

- Built with React + Tailwind CSS..

- Header fixed to the top with logo,
  - map for reusable nav items
  - Implemented HashLink (react-router-hash-link) for smooth scrolling to sections

- Hero/About: responsive text and layout.

- Services: responsive grid of service cards, with data mapping to avoid repetition.

- Contact section with address, nd contact form with inputs

- Footer with responsive layout (used react icons)

- Responsive Design using Tailwind breakpoints
